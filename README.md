# Rock Paper Scissors

A simple and interactive Rock Paper Scissors game built with Python and Tkinter.

## Features

- Rock, Paper and Scissors gameplay
- Circular 3D buttons
- Modern neon-style interface
- Button press animation
- Win, Lose and Draw result popup
- Live score tracking
- Reset Game button
- Exit button
- Separate sound effects for Win, Lose and Draw

## Technologies Used

- Python
- Tkinter
- Random
- Winsound
- Git
- GitHub
